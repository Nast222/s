Expense TrackerАвтор: [Федосеев]
Описание: Простое приложение для учёта личных расходов с графическим интерфейсом.Функции:

Добавление расходов (сумма, категория, дата).
Фильтрация по категории и дате.
Подсчёт суммы за выбранный период.
Сохранение и загрузка данных из файла expenses.json.Как использовать:
Запустите main.py.
Введите сумму (число), категорию и дату (ГГГГ-ММ-ДД).
Нажмите «Добавить расход».
Используйте фильтры и расчёт суммы.Пример использования:
Добавить расход: 500 ₽ на «Еду» за 2026-05-01.
Посчитать сумму с 2026-04-25 по 2026-05-02.Технологии: Python 3.x + Tkinter + JSON.
